# 샘플 CSV

MVP 시연용 카드 CSV 샘플입니다. `/csv-upload` 화면에서 그대로 업로드하면 동작합니다.

## 포맷 가이드

헤더: `이용일, 가맹점명, 이용금액, [카테고리]`

- 이용일: `YYYY-MM-DD`, `YYYY.MM.DD`, `YYYY/MM/DD` 모두 허용
- 가맹점명: 쿠팡/네이버/무신사 표기의 다양한 변형을 자동 정규화
  (예: "쿠팡(주)", "COUPANG", "네이버페이", "N-Pay", "무신사", "MUSINSA")
- 이용금액: 쉼표와 "원" 기호 제거 후 숫자 파싱
- 카테고리(선택): 생활용품/패션/전자기기/식품 중 하나. 없거나 미일치 시 "생활용품"으로 기본 매핑

플랫폼 정규화 규칙에 매칭되지 않는 가맹점은 업로드 시 "건너뛴 행"으로 표시됩니다.
